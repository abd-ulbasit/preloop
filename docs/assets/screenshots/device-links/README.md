Real browser captures from a local Enterprise stack seeded with synthetic data:
Jane Doe, two workstation runners without fingerprints, no expected-device roster,
two managed agents, a discovered candidate, and a model configured on an agent and
a flow. No provider calls or production data are used.

The `before-*` captures show the previous console. The `after-*` captures show the
device fleet redesign and links between devices, agents and configured models.

The model page shows the same budget-policy load error in both captures. This is
a limitation of the local capture stack, independent of the configured-consumer
section being demonstrated.
